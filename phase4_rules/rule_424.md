## § 424. अस् 'to be' - Complete Paradigm

@deva[अस्] P. (Ā.[^1] rare) 'to be'—drops its @deva[अ] before weak terminations and @deva[त्] before a termination beginning with @deva[स्] and @deva[ध्व्]. Before 2 and 3 Imperf. it takes the augment @deva[ई]. It is irregular in many respects.

### Present

| | Parasmaipada | | | Ātmanepada | | |
|---|---|---|---|---|---|---|
| 1. | @deva[अस्मि] | @deva[स्वः] | @deva[स्मः] | @deva[हे] | @deva[स्वहे] | @deva[स्महे] |
| 2. | @deva[असि] | @deva[स्थः] | @deva[स्थ] | @deva[से] | @deva[साथे] | @deva[ध्वे] |
| 3. | @deva[अस्ति] | @deva[स्तः] | @deva[सन्ति] | @deva[स्ते] | @deva[स्थाते] | @deva[सते] |

### Imperfect

| | Parasmaipada | | | Ātmanepada | | |
|---|---|---|---|---|---|---|
| 1. | @deva[आसम्] | @deva[आस्व] | @deva[आस्म] | @deva[आसि] | @deva[आस्वहि] | @deva[आस्महि] |
| 2. | @deva[आसीः] | @deva[आस्तम्] | @deva[आस्त] | @deva[आस्थाः] | @deva[आसाथाम्] | @deva[आध्वम्] |
| 3. | @deva[आसीत्] | @deva[आस्ताम्] | @deva[आसन्] | @deva[आस्त] | @deva[आसाताम्] | @deva[आसत] |

### Imperative

| | Parasmaipada | | | Ātmanepada | | |
|---|---|---|---|---|---|---|
| 1. | @deva[असानि] | @deva[असाव] | @deva[असाम] | @deva[असै] | @deva[असावहै] | @deva[असामहै] |
| 2. | @deva[एधि] | @deva[स्तम्] | @deva[स्त] | @deva[स्व] | @deva[साथाम्] | @deva[ध्वम्] |
| 3. | @deva[अस्तु] | @deva[स्ताम्] | @deva[सन्तु] | @deva[स्ताम्] | @deva[साताम्] | @deva[सताम्] |

### Potential

| | Parasmaipada | | | Ātmanepada | | |
|---|---|---|---|---|---|---|
| 1. | @deva[स्याम्] | @deva[स्याव] | @deva[स्याम] | @deva[सीय] | @deva[सीवहि] | @deva[सीमहि] |
| 2. | @deva[स्याः] | @deva[स्यातम्] | @deva[स्यात] | @deva[सीयाः] | @deva[सीयाथाम्] | @deva[सीध्वम्] |
| 3. | @deva[स्यात्] | @deva[स्याताम्] | @deva[स्युः] | @deva[सीत] | @deva[सीयाताम्] | @deva[सीरन्] |

---
[^1]: @deva[अस्] is Ātmanepadi in a few cases. Cf. Bhattikavya II. 35 '@deva[अन्यो व्यतिते तु प्रभावि वधः]' &c. where it implies @deva[कर्मव्यतिहार] or an exchange of duty.
