# Phase 4: Unified Images

This directory contains a unified, gap-free set of page images for
Kale's Higher Sanskrit Grammar, renamed to match internal page numbers.

## Image Sources

- **official_1931**: 715 images
- **dli_2015**: 0 images
- **Missing**: 0 images
- **TOTAL**: 715 images

## Naming Convention

Images are named `NNN.png` where NNN is the **internal page number**
as shown at the top of each page in the original text.

## Priority

When both sources had an image for the same page:
1. official_1931 (higher quality) was preferred
2. dli_2015 was used as fallback
