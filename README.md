# Kale's Higher Sanskrit Grammar - OCR Digitization Project

This repository contains the digitized version of Kale's 'A Higher Sanskrit Grammar' (1931).

## Files
- `kales_sanskrit_grammar_complete.md` - Complete digitized book
- `ocr_pages.py` - Extract pages from PDF via OCR
- `create_chunks.py` - Create overlapping chunks for processing
- `cleanup_chunks.sh` - Clean chunks via Claude
- `aggregate_cleaned_chunks.py` - Aggregate into final book
- `STRUCTURE.md` - Documentation of book structure
